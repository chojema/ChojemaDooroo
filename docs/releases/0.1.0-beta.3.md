- 앱 이름을 Chojema Docs에서 Chojema Dooroo로 변경하고 실행 파일과 설치 파일 이름을 `ChojemaDooroo`로 전환.
- 기존 설치본의 설정과 자동 업데이트 연결을 유지하기 위해 `appId`(`io.github.chojema.docs`)와 사용자 데이터 폴더 이름은 유지.
- GitHub 저장소와 업데이트·배포 주소를 `chojema/ChojemaDooroo`로 전환.
