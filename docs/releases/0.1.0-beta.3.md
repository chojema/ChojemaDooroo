제품 이름과 GitHub 저장소를 Chojema Dooroo(`chojema/ChojemaDooroo`)로 변경한 시험 배포입니다.

- 앱 이름을 Chojema Docs에서 Chojema Dooroo로 변경하고 실행 파일과 설치 파일 이름을 `ChojemaDooroo`로 전환.
- 기존 설치본의 설정과 자동 업데이트 연결을 유지하기 위해 `appId`(`io.github.chojema.docs`)와 사용자 데이터 폴더 이름은 유지.
- GitHub 저장소와 업데이트·배포 주소를 `chojema/ChojemaDooroo`로 전환.
- HWP와 HWPX 열기 및 저장, 새 문서는 HWPX로 기본 저장, 문서 탭·나란히 보기·별도 창 분리 제공.

제작 및 유지관리: Chojema.

Windows x64 설치 파일을 내려받아 실행하세요. 코드 서명이 없는 시험판입니다. 실제 업무 문서에는 복사본으로 호환성을 확인한 뒤 사용하세요. DOC와 DOCX 편집은 지원하지 않습니다. macOS는 별도 빌드와 검증 예정입니다.

원본과 제삼자 구성요소의 저작권 및 라이선스 고지는 설치 폴더에 포함되어 있습니다.
