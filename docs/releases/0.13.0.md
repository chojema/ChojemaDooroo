워드식 인터페이스를 기본으로 사용하고, 한글 앱에 익숙한 사용자는 한글 스타일로 전환할 수 있도록 편집 용어와 화면을 보완했습니다.

- **스타일 선택:** 도구 > 환경 설정 > 일반 > 인터페이스 스타일에서 `워드 스타일 (기본값)` 또는 `한글 스타일`을 고릅니다. 열려 있는 모든 편집기에 즉시 적용되며 다음 실행에도 유지됩니다. 기존에 선택한 한글 스타일도 유지합니다.
- **메뉴와 편집 용어:** 삽입·레이아웃 메뉴, 실행 취소·잘라내기·붙여넣기·서식 복사, 글꼴·단락·번호 매기기·글머리 기호, 문자 간격·배율과 개체 배치까지 전환 범위를 확대했습니다. 도구 모음과 도구 설명에도 같은 용어를 사용합니다.
- **단락 나눔 옵션:** 외톨이줄 보호는 `단락의 첫 줄이나 마지막 줄 분리 방지`, 문단 보호는 `현재 단락을 나누지 않음`처럼 기능을 알아보기 쉬운 워드식 표현으로 표시합니다. 한글 스타일을 고르면 기존 표현으로 돌아옵니다.
- **대화상자:** 단락과 글꼴 창의 탭 이름을 스타일에 맞게 표시하고, 긴 옵션명이 잘리지 않도록 공간을 확보했습니다. 작은 창에서는 단락 설정 영역을 스크롤해 아래쪽 항목까지 사용할 수 있습니다.
- **내용 보존:** 스타일 전환은 문서 내용·서식·단축키와 설정값을 변경하지 않습니다. 사용자 스타일·글꼴·책갈피 이름도 그대로 표시합니다.

Windows x64와 macOS Apple Silicon용 설치 파일을 제공합니다. 기존 HWP/HWPX 편집과 AI 도우미·MCP 기능을 유지합니다.
