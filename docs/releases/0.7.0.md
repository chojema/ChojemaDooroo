외부 MCP 클라이언트에서 HWP/HWPX 문서를 열고 읽고 편집하고 저장할 수 있는 버전입니다.

- **문서 자동화:** 문서 목록·열기·생성, 텍스트 읽기·찾기·교체·문단 삽입, 표 목록·읽기·셀 채우기·삽입, HWP/HWPX 저장 등 12개 도구를 제공합니다.
- **접근 범위:** 허용할 문서 폴더를 지정하며, 읽기 전용 모드에서는 조회 도구 6개만 제공합니다. 일반 앱과 별도 프로필로 실행됩니다.
- **저장 보호:** MCP 모드는 명시적으로 저장하며, 기존 파일은 덮어쓰기를 지정해야 합니다. 외부 변경을 감지하면 저장을 거부하고, 기존 앱의 백업·형식 보정·원자적 쓰기를 사용합니다.
- **연결:** 설치본과 함께 아래의 `mcp.mjs`를 내려받고 Node.js 24 LTS로 실행하세요. `--app`에는 설치된 앱 실행 파일, `--mcp-root`에는 문서 폴더의 절대 경로를 지정합니다. [MCP 연결 안내](https://github.com/chojema/ChojemaDooroo/blob/v0.7.0/docs/mcp.md)에 클라이언트 설정 예제가 있습니다.

Windows x64는 `ChojemaDooroo-Setup-0.7.0-x64.exe`, macOS Apple Silicon은 `ChojemaDooroo-0.7.0-arm64.dmg`를 사용하세요. Mac은 ad-hoc 서명이며 Developer ID 서명·공증과 자동 업데이트는 제공하지 않습니다.
