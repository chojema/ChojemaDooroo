쪽을 그림 파일로 내보내고, PDF를 편집할 수 있는 문서로 가져올 수 있게 한 버전입니다.

- `파일 › PNG 그림으로 내보내기…`와 `JPG 그림으로 내보내기…`로 쪽마다 그림 파일을 하나씩 만듭니다. A4 한 쪽은 1587×2245 픽셀(192dpi)이며, 여러 쪽이면 `문서-01.png`, `문서-02.png`처럼 번호가 붙습니다. 같은 이름의 파일이 있으면 덮어쓰므로 빈 폴더를 고르는 것이 안전합니다.
- `열기`에서 PDF를 고르거나 PDF를 창에 끌어다 놓으면, PDF의 텍스트가 편집할 수 있는 새 문서로 열립니다. 줄은 문단으로 다시 이어지고 글자 크기, 쪽 나눔, 용지 크기를 따릅니다. 처음 저장할 때 저장할 위치를 묻습니다.
- PDF의 그림, 표, 도형, 굵게 같은 글자 꾸밈은 가져오지 않습니다. 여러 단으로 짠 PDF는 줄 순서가 섞일 수 있습니다. 스캔한 PDF와 암호가 걸린 PDF는 안내 후 열지 않습니다.

Windows x64 설치 파일(`ChojemaDooroo-Setup-0.4.0-x64.exe`)을 내려받아 실행하세요. macOS Apple Silicon용 DMG(`ChojemaDooroo-0.4.0-arm64.dmg`)는 Developer ID 서명과 공증 없이 ad-hoc 서명만 되어 있으므로, 처음 실행할 때 Finder에서 앱을 Control-클릭한 뒤 `열기`를 선택하세요. 코드 서명이 포함되어 있지 않으므로 중요한 문서는 복사본으로 호환성을 확인한 뒤 사용하세요.
