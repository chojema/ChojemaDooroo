Markdown·Word·HTML 문서를 가져오고, 편집한 내용을 원하는 형식으로 내보낼 수 있는 버전입니다.

- **가져오기:** 파일 열기와 드래그앤드롭으로 MD/Markdown, Word(DOCX), HTML/HTM을 새 HWPX 문서로 가져옵니다. 구형 Word(DOC)는 본문 텍스트만 가져옵니다.
- **내보내기:** 파일 메뉴에서 Markdown, Word(.docx), HTML 사본을 만듭니다. 현재 편집 내용이 포함되며 기존 HWP/HWPX 저장 대상은 유지됩니다.
- **변환 범위:** 본문, 기본 글자 서식, 표, 포함된 그림을 중심으로 지원합니다. 원본 파일은 유지하며 변환 결과는 별도로 저장합니다.
- **보호:** 문서 크기와 DOCX 확장량을 검사하고, 스크립트 실행과 외부 그림 다운로드를 막습니다. 문서 폴더 안의 상대 경로 그림은 가져올 수 있습니다.

복잡한 배치·도형·머리말·꼬리말·각주·메모·변경 추적과 일부 글자 서식은 보존되지 않을 수 있습니다. 링크는 표시 문자 뒤에 주소를 남기며, Markdown의 병합·중첩 표는 HTML 표로 내보냅니다.

기존 HWP/HWPX 편집, PDF 텍스트 가져오기, PDF·PNG·JPG 내보내기, 워드·한글 인터페이스 스타일, AI 도우미와 MCP 기능을 유지합니다. Windows x64와 macOS Apple Silicon용 설치 파일을 제공합니다.
