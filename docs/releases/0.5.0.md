내보낼 페이지를 고를 수 있게 한 버전입니다.

- `PDF로 내보내기`, `PNG 그림으로 내보내기`, `JPG 그림으로 내보내기`에서 `문서 전체`, `현재 페이지`, `페이지 범위`를 고릅니다. 1페이지짜리 문서는 묻지 않고 바로 저장 위치를 묻습니다.
- `현재 페이지`는 커서가 있는 페이지입니다. 범위는 `1-3, 5`나 `8-`(8페이지부터 끝까지)처럼 입력합니다.
- 일부 페이지를 그림으로 내보내면 파일 이름에 실제 페이지 번호가 붙습니다(`문서-03.png`). 한 페이지만 고르면 입력한 이름 그대로 저장합니다.
- 인쇄는 지금처럼 시스템 인쇄 창에서 범위를 고릅니다.

Windows x64 설치 파일(`ChojemaDooroo-Setup-0.5.0-x64.exe`)을 내려받아 실행하세요. macOS Apple Silicon용 DMG(`ChojemaDooroo-0.5.0-arm64.dmg`)는 Developer ID 서명과 공증 없이 ad-hoc 서명만 되어 있으므로, 처음 실행할 때 Finder에서 앱을 Control-클릭한 뒤 `열기`를 선택하세요. 코드 서명이 포함되어 있지 않으므로 중요한 문서는 복사본으로 호환성을 확인한 뒤 사용하세요.
