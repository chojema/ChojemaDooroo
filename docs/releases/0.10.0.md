AI 도우미와 대화해 MCP를 자동 등록·연결하고, 없는 글꼴을 알기 쉽게 안내하는 버전입니다.

- **표준 글꼴 폴더만 사용:** 시스템 공용 글꼴 폴더와 운영체제의 표준 사용자 글꼴 폴더에 있는 글꼴만 사용합니다. 편집 화면, 인쇄 미리보기, 인쇄와 PDF·그림 내보내기에 같은 기준을 적용합니다.
- **대체 글꼴 안내:** 없는 글꼴은 비슷한 글꼴로 대신 보여 주며, 원본 글꼴 이름은 그대로 저장합니다. 알림이 사라진 뒤에도 상단의 **대체 글꼴 안내**에서 전체 목록과 사용 범위, 별도 설치 글꼴의 사용권 확인 안내를 다시 볼 수 있습니다.
- **MCP 자동 등록·연결:** AI 도우미에게 *"초제마 두루 MCP 연결해 줘"*라고 말하거나 **설정 > MCP 자동 등록 > 외부 AI에 자동 등록** 버튼으로 Claude Desktop, Claude Code, Cursor, Windsurf, Antigravity에 MCP 서버를 등록합니다. 앱 내 AI 도우미에 외부 MCP 서버를 대화로 연결해 그 도구를 바로 쓸 수도 있습니다. 자세한 내용은 [MCP 연결 안내](https://github.com/chojema/ChojemaDooroo/blob/v0.10.0/docs/mcp.md)를 참고하세요.

Windows x64는 `ChojemaDooroo-Setup-0.10.0-x64.exe`, macOS Apple Silicon은 `ChojemaDooroo-0.10.0-arm64.dmg`를 사용하세요. Mac은 ad-hoc 서명이며 Developer ID 서명·공증과 자동 업데이트는 제공하지 않습니다. 수동 연결용 MCP 실행기는 아래의 `mcp.mjs`를 사용할 수도 있습니다.
