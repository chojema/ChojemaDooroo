인쇄 미리보기와 문서 점검을 더하고, 표 편집을 한컴 한글 방식에 가깝게 다듬은 버전입니다.

- **인쇄 미리보기:** `파일 > 미리 보기`와 `Ctrl+P`로 열어 페이지 넘기기, 확대, 맞쪽·여러 페이지 보기, 여백 보기를 한 뒤 인쇄합니다. PDF·PNG·JPG 내보내기의 페이지 선택 창은 그대로입니다.
- **문서 점검:** 행정안전부 행정문서 작성 가이드라인 기준으로 AI 없이 문서를 검사합니다. 글꼴은 점검 창에서 바로 바꾸고, 나머지는 AI 요청 글로 넘길 수 있습니다.
- **표 편집:** 셀 붙이기 창, 셀 블록 글쇠, 병합 셀이 있는 표의 크기 조절, 표 자동 채우기, 세 번 클릭과 낱말 단위 끌기 선택을 추가했습니다.
- **입력과 정보:** 입력한 낱말의 한자 변환(한자 키·`F9`), 문서 정보(글자 수·원고지 매수), 곡선따옴표를 추가하고 PC 글꼴을 바로 찾도록 했습니다.
- **AI 문서 도우미:** 문서 속 그림을 볼 수 있고, 50MB가 넘는 HWPX도 글자 부분만 읽어 첨부할 수 있습니다.
- **렌더링 엔진 교체:** 병합 셀 표, 맞쪽 바탕쪽, 그림 밝기·대비, 쪽 번호, 문단 뒤 표의 겹침을 고쳤습니다. 칸을 세로로 합친 표가 든 HWPX를 한컴 한글에서 열지 못하던 문제도 고쳤습니다.
- **오류 수정:** 제어된 폴더 액세스가 켜진 Windows에서 첫 실행 때 앱이 멈출 수 있던 문제를 고쳤습니다.

Windows x64 설치 파일(`ChojemaDooroo-Setup-0.6.0-x64.exe`)을 내려받아 실행하세요. macOS Apple Silicon용 DMG(`ChojemaDooroo-0.6.0-arm64.dmg`)는 Developer ID 서명과 공증 없이 ad-hoc 서명만 되어 있으므로, 처음 실행할 때 Finder에서 앱을 Control-클릭한 뒤 `열기`를 선택하세요. 코드 서명이 포함되어 있지 않으므로 중요한 문서는 복사본으로 호환성을 확인한 뒤 사용하세요.
