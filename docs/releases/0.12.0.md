AI 도우미를 이 PC에서 실행되는 Ollama 모델로 쓸 수 있는 버전입니다.

- **Ollama (이 PC에서 실행):** **도구 > 환경 설정 > AI 도우미**의 제공업체에서 고를 수 있습니다. 실행 중인 Ollama에 설치된 모델을 목록으로 보여 주며, 문서 내용은 이 PC 밖으로 나가지 않습니다.
- **모델 안내:** 도구 호출을 지원하지 않는 모델은 `문서 편집 제한`으로 표시되고, 고르면 표 편집이나 글꼴 바꾸기 같은 기능이 제한될 수 있다고 알려 줍니다. 응답 속도와 정확도는 PC 성능과 모델에 따라 다릅니다.
- 두루는 Ollama를 설치하거나 모델을 내려받지 않으며, 자동 선택에도 포함하지 않습니다. 직접 고른 경우에만 사용합니다.

Windows x64는 `ChojemaDooroo-Setup-0.12.0-x64.exe`, macOS Apple Silicon은 `ChojemaDooroo-0.12.0-arm64.dmg`를 사용하세요. Mac은 ad-hoc 서명이며 Developer ID 서명·공증과 자동 업데이트는 제공하지 않습니다. 수동 연결용 MCP 실행기는 아래의 `mcp.mjs`를 사용할 수도 있습니다.
