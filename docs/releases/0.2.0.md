상단 메뉴를 정리해 문서 편집 화면을 넓힌 버전입니다.

- 앱 도구 모음 줄과 Windows 창 메뉴 줄을 없앴습니다. 문서 탭이 창 제목 바로 아래에 오고 편집 영역이 넓어졌습니다.
- 새 문서, 열기, 문서 닫기는 편집기의 `파일` 메뉴에, 홈·나란히 보기·창으로 분리는 `보기` 메뉴에, 설정·업데이트 확인·정보는 `도구` 메뉴에 있습니다.
- 정보 메뉴는 `도구 › Chojema Dooroo 정보` 하나로 합쳤습니다.
- 문서가 없을 때는 홈 화면 하단의 `설정` 링크로 설정을 열 수 있습니다.

Windows x64 설치 파일(`ChojemaDooroo-Setup-0.2.0-x64.exe`)을 내려받아 실행하세요. 코드 서명이 포함되어 있지 않으므로 중요한 문서는 복사본으로 호환성을 확인한 뒤 사용하세요.
