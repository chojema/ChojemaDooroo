인터페이스 용어를 Word 스타일과 HWP 스타일 중에서 고를 수 있게 한 버전입니다.

- `설정 › 인터페이스 용어`에서 Word 스타일(단락·페이지·글꼴)과 HWP 스타일(문단·쪽·글자 모양) 중 하나를 고를 수 있습니다. 초기값은 Word 스타일입니다.
- 바꾼 용어는 저장되며 열려 있는 모든 편집기의 메뉴, 도구 설명, 대화상자, 상태 표시줄, 메모, 인쇄 안내에 바로 반영됩니다. 문서 내용, 저장 형식, 단축키는 바뀌지 않습니다.
- macOS Apple Silicon용 앱 패키징을 지원합니다.

Windows x64 설치 파일(`ChojemaDooroo-Setup-0.3.0-x64.exe`)을 내려받아 실행하세요. macOS Apple Silicon용 DMG(`ChojemaDooroo-0.3.0-arm64.dmg`)는 Developer ID 서명과 공증 없이 ad-hoc 서명만 되어 있으므로, 처음 실행할 때 Finder에서 앱을 Control-클릭한 뒤 `열기`를 선택하세요. 코드 서명이 포함되어 있지 않으므로 중요한 문서는 복사본으로 호환성을 확인한 뒤 사용하세요.
