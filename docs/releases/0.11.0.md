설정을 한곳에 모아 찾기 쉽게 정리한 버전입니다.

- **환경 설정 하나로 통합:** 도구 메뉴의 **환경 설정**에서 모든 설정을 바꿉니다. 일반(인터페이스 용어·화면 테마), 파일(복구용 자동 저장·쉴 때 자동 저장·PDF 저장 안내), 글꼴, AI 도우미, MCP, 업데이트 탭으로 나뉘며, 홈 화면의 **환경 설정**도 같은 창을 엽니다. 바꾼 편집기 옵션은 열려 있는 모든 문서에 바로 적용됩니다.
- **글꼴 탭 정리:** 표준 글꼴 폴더에 설치된 글꼴을 자동으로 쓴다는 안내와 함께, 현재 문서의 대체 글꼴 보기, 최근 사용 글꼴 표시, 대표 글꼴 등록을 한 화면에서 할 수 있습니다.
