앱 아이콘을 새로 디자인한 버전입니다. 문서 기능은 0.4.0과 같습니다.

- 문서와 H 글자를 얹은 기존 아이콘을 코발트 블루 바탕에 입력 커서를 품은 D 로고로 바꿨습니다.
- Windows의 작은 아이콘(16~32픽셀)은 획을 굵게 한 전용 그림을 쓰고, macOS 아이콘은 1024픽셀까지 선명하게 표시됩니다.
- 설치 후에도 운영체제의 아이콘 캐시 때문에 한동안 이전 아이콘이 보일 수 있습니다.

Windows x64 설치 파일(`ChojemaDooroo-Setup-0.4.1-x64.exe`)을 내려받아 실행하세요. macOS Apple Silicon용 DMG(`ChojemaDooroo-0.4.1-arm64.dmg`)는 Developer ID 서명과 공증 없이 ad-hoc 서명만 되어 있으므로, 처음 실행할 때 Finder에서 앱을 Control-클릭한 뒤 `열기`를 선택하세요. 코드 서명이 포함되어 있지 않으므로 중요한 문서는 복사본으로 호환성을 확인한 뒤 사용하세요.
