PNG·JPG 내보내기에서 빈 그림이 저장될 수 있던 문제를 막은 버전입니다.

- 페이지가 그려지기 전의 빈 화면이 그림 파일로 저장될 수 있던 경로를 막았습니다. 페이지가 그려진 것을 확인한 뒤에만 저장하고, 끝내 그려지지 않으면 빈 파일을 남기지 않고 오류로 알립니다.
- 그림의 크기와 파일 이름, 다른 기능은 0.5.0과 같습니다.

Windows x64 설치 파일(`ChojemaDooroo-Setup-0.5.1-x64.exe`)을 내려받아 실행하세요. macOS Apple Silicon용 DMG(`ChojemaDooroo-0.5.1-arm64.dmg`)는 Developer ID 서명과 공증 없이 ad-hoc 서명만 되어 있으므로, 처음 실행할 때 Finder에서 앱을 Control-클릭한 뒤 `열기`를 선택하세요. 코드 서명이 포함되어 있지 않으므로 중요한 문서는 복사본으로 호환성을 확인한 뒤 사용하세요.
