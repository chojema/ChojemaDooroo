Chojema Docs의 첫 공개 시험 배포입니다. HWP와 HWPX 문서를 한 앱에서 작성하고, 탭과 별도 창으로 함께 사용할 수 있습니다.

- HWP와 HWPX 열기 및 저장, 새 문서는 HWPX로 기본 저장.
- 문서 탭, 두 문서 나란히 보기, 창으로 분리.
- 화면 테마 설정과 Windows 업데이트 확인.
- 앱과 Windows 실행 파일의 제작자 정보를 Chojema로 통일하고 배포 과정에서 검사.

제작 및 유지관리: Chojema.

Windows x64 설치 파일을 내려받아 실행하세요. 코드 서명이 없는 시험판입니다. 실제 업무 문서에는 복사본으로 호환성을 확인한 뒤 사용하세요. DOC와 DOCX 편집은 지원하지 않습니다. macOS는 별도 빌드와 검증 예정입니다.

원본과 제삼자 구성요소의 저작권 및 라이선스 고지는 설치 폴더에 포함되어 있습니다.
