# 0.1.0-beta.2 검증

2026. 10. 30. Windows x64에서 확인했습니다.

- HWP 관련 단위 검사 925개 통과.
- 전용 앱과 공용 문서 도우미의 단위 검사 36개 통과.
- 전용 앱과 HWP 모듈 타입 검사 통과.
- Windows 실행 파일의 제품명 Chojema Docs와 회사명 Chojema, 앱 패키지의 단독 작성자 메타데이터 확인.
- 실제 앱에서 문자 입력 후 HWPX 저장, HWP로 저장, HWP 재열기, HWPX 재저장 시 입력 문자열 유지 확인.
- HWPX 기본 저장 형식, 두 문서 나란히 보기, 창 분리 시 같은 편집기 프로세스 유지, 화면 테마 변경 확인.
- 최종 패키징한 Windows 실행 파일에서도 같은 실제 앱 검사 통과. 검사 중 관련 앱 오류 없음.
- 공개 허용 목록과 인증 정보 패턴 검사 통과. Gitleaks 8.30.1로 공개 대상 소스를 독립 검사하여 탐지 없음.

검증에 생성한 문서는 임시 시험 문서입니다. 복잡한 실제 문서 전체의 시각적 호환성을 보증하지 않습니다. Microsoft Word와 한컴 한글에서 모든 개체를 대조한 검증은 수행하지 않았습니다.

Windows 설치 마법사, 실제 후속 릴리스로의 자동 업데이트 전체 경로, macOS 빌드와 실행은 별도 확인 대상입니다. 코드 서명은 없습니다.
